# Assets Folder

Place your images in this folder. The following images are required:

## Required Images:

1. **logo.png** - FIZZ logo for header and footer
2. **mascot-happy.png** - Happy mascot for hero section
3. **mascot-gift.png** - Mascot with gift for about section
4. **face-lamp.png** - Custom face/memory lamp
5. **lamp-character.png** - Character mood lamp
6. **robot-sprue.png** - OLED robot/keychain

## Image Specifications:
- Recommended size: 500x500px or larger
- Format: PNG with transparency preferred
- Keep file sizes reasonable for web performance

## Temporary Solution:
If you don't have images yet, you can:
1. Use placeholder images from services like placeholder.com
2. Create simple colored squares as temporary placeholders
3. Update the image paths in `src/data.js` to point to online images
